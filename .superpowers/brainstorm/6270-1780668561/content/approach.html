Approche de redesign — Mobile EDP

3 écrans à migrer vers le thème light : Messages, Profil, Reels

A

Fidèle au design spec web

Messages et Profil calqués exactement sur la spec web (section 4 du design doc). Reels reste dark (fond noir, contenu vidéo). Profil : avatar 72px, stats row, loyalty badge pill, tabs grid/film/bookmark, grille 3 colonnes 1:1.

Pour

  • Cohérence maximale web/mobile
  • Design déjà validé

Contre

  • Grille photos (posts vides = placeholders)
B

Adapté mobile-first

Messages enrichi avec indicateur de non-lus (badge rouge). Profil avec cover photo + sticky header (comme Instagram). Reels dark avec overlay amélioré. Quelques patterns mobile natifs ajoutés (pull-to-refresh, swipe actions).

Pour

  • Expérience native optimisée
  • Plus proche des apps de référence

Contre

  • Déviation du design spec
  • Scope plus large
C

Minimal — thème seulement

Conversion mécanique dark → light : remplacer #0A0A0A par colors.background, #fff par colors.foreground, #888 par colors.muted. Structure identique, zéro nouvelles fonctionnalités.

Pour

  • Rapide, risque minimal

Contre

  • Résultat basique, icônes structurelles emoji restent

Ma recommandation : A — cohérent avec le travail déjà fait sur feed/explore/establishment.
